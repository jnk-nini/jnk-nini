# CSELC01C Cloud Databases Reviewer

Reviewer for **Cloud Databases and Data Services, Volume 1 & 2** (CSELC01C - Cloud Computing Development).

Static site, no build step. Works offline through a service worker (`sw.js`).

- `data_notes.js`: study notes per lesson, in the slides' wording
- `data_facts.js`: glossary terms (flashcards, identification, "which term?")
- `data_cloze.js`: missing-word items (prof-style multiple choice, fill in the blank)
- `data_tf.js`: true or false items; false ones carry the "counter" phrase
- `data_more.js`: concept multiple choice, list recall, spelling traps, counter statements, look-alike pairs
- `app.js`: the app; `style.css`: styles
